# Parallax Specification

## Purpose

Investigate complementary chest X-ray view synthesis from one available view without declaring any candidate model final.

## Requirements

### Requirement: Explicit experimental status

Each Parallax proposal SHALL identify the source and target views, candidate method, data assumptions, and whether the method is a hypothesis, published approach, or available implementation.

### Requirement: Anatomical evaluation

Each meaningful evaluation SHALL assess image consistency and clinically relevant thoracic anatomy rather than visual appearance alone.
