# Voluma Specification

## Purpose

Investigate whole-chest 3D CT reconstruction from real and/or synthetic multi-view chest X-rays.

## Requirements

### Requirement: View provenance

Each experiment SHALL record whether every input view is real or synthetic and how it was generated.

### Requirement: Whole-chest scope

Evaluation SHALL consider lungs, ribs, chest wall, soft tissue, heart, mediastinum, and overall thoracic structure when data and reference annotations permit.
