# RadioVue Research Records

This directory preserves three different kinds of project knowledge. Do not merge them.

- `notes/` records externally sourced research and clearly labels evidence type.
- `failed-experiments/` records attempted approaches that were abandoned or rejected.
- `decisions/` records meaningful project choices and their rationale.

Use dated Markdown files with descriptive, lowercase, hyphenated names. Do not store patient-identifying information, raw medical images, credentials, or unrestricted dataset copies here.
